# BTC Tracker Bot

Telegram-бot, который раз в минуту опрашивает несколько независимых источников курса **Bitcoin**,
а также официальный курс **USD/EUR/RUB → BYN** (Нацбанк Беларуси + курсы Belarusbank), и:

- присылает **алерты** — вы указываете цену BTC, бот пишет, когда она будет достигнута;
- каждый день в **08:00, 14:00, 20:00, 23:59** (время Минска, настраивается) шлёт сводку с курсами;
- следит за доступностью источников и сообщает владельцу, если что-то надолго отвалилось;
- при запуске/перезапуске сразу присылает текущие курсы и сообщает, сколько бот простаивал.

Код полностью рабочий и покрыт тестами — «заготовки» здесь только в `.env`: реальный токен бота
и ваш Telegram ID вы вставляете сами (см. [Настройка](#настройка)).

## Как устроен доступ

- **Владелец** — Telegram ID из `OWNER_ID` в `.env`. Доступ у него есть всегда, он не хранится в БД
  и не может быть отозван через бота. Если `OWNER_ID` не задан, бот работает в режиме настройки:
  любому, кто напишет `/start`, он покажет его Telegram ID и попросит вписать его в `.env`.
- **Остальным пользователям** доступ выдаётся тремя способами (всё уже реализовано):
  1. **Ссылка-приглашение** — кнопка «➕ Пригласить» в разделе «👑 Админ» создаёт одноразовую ссылку
     вида `https://t.me/ваш_бот?start=inv_...`, действует 24 часа (`INVITE_TTL_HOURS`).
  2. **Запрос доступа** — если написать боту без приглашения, он отправит владельцу карточку с кнопками
     «✅ Разрешить» / «❌ Отклонить».
  3. **По Telegram ID** — команда `/adduser 123456789` или кнопка «🆔 Добавить по ID» в админке.

Доступ и роль (владелец/пользователь) хранятся в БД; у владельца дополнительно есть кнопка
«❌ Удалить доступ» напротив каждого пользователя (кроме других владельцев).

## Структура проекта

```
bot/
  config.py        — чтение и проверка .env
  db.py             — PostgreSQL (asyncpg): пользователи, приглашения, алерты, история цен
  access.py         — кто и как получает доступ
  rates/            — источники курсов и их агрегация в одну цену
    btc_providers.py   — 13 бирж/агрегаторов для BTC/USD
    fiat_providers.py  — НБРБ, Belarusbank, 2 международных резервных источника BYN
    service.py         — опрос, отсев выбросов, защита от «скачков» цены
  alerts.py         — бизнес-правила алертов (создание, срабатывание, гистерезис повтора)
  scheduler.py      — фоновые циклы: опрос курсов, ежедневные сводки, здоровье источников
  handlers/         — обработчики aiogram (курсы, алерты, сводки, админка, доступ)
  texts.py          — все тексты сообщений
  keyboards.py      — все inline- и reply-клавиатуры
  main.py           — сборка приложения и запуск
deploy/
  btc-tracker-bot.service — systemd-юнит (автозапуск и авто-перезапуск при падении)
tests/              — pytest: чистая логика + БД-тесты на реальном PostgreSQL
```

## Настройка

### 1. Установить зависимости

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Создать бота и базу данных

1. У [@BotFather](https://t.me/BotFather): `/newbot` → скопировать токен.
2. Узнать свой Telegram ID: временно запустить бота без `OWNER_ID` и отправить ему `/start` —
   он покажет ID (или спросите [@userinfobot](https://t.me/userinfobot)).
3. Создать базу PostgreSQL на вашем сервере:
   ```bash
   sudo -u postgres createuser btc_bot -P
   sudo -u postgres createdb btc_tracker -O btc_bot
   ```
   Таблицы бот создаёт сам при первом запуске (миграции в `bot/db.py`).

### 3. Заполнить `.env`

```bash
cp .env.example .env
```

Откройте `.env` и укажите `BOT_TOKEN`, `OWNER_ID`, `DATABASE_URL` — остальное можно оставить
по умолчанию (комментарии в файле объясняют каждый параметр).

### 4. Проверить доступность источников курсов **с сервера**

НБРБ и Belarusbank обычно отвечают только с белорусских IP — стоит проверить именно с сервера,
на котором будет жить бот:

```bash
python -m bot --check-apis
```

Команда ничего не пишет в Telegram и не трогает БД — только опрашивает источники и печатает,
что доступно, а что нет.

### 5. Запустить

```bash
python -m bot
```

## Автозапуск и авто-перезапуск при падении

Чтобы бот поднимался при старте сервера и перезапускался при любом сбое — используйте systemd
(инструкция и все команды — в комментариях самого файла):

```bash
# отредактируйте пути и пользователя внутри файла перед копированием
sudo cp deploy/btc-tracker-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now btc-tracker-bot
```

`Restart=always` + `StartLimitIntervalSec=0` — systemd продолжает пытаться перезапустить бота,
даже если несколько попыток подряд оказались неудачными (например, сеть или БД ещё не поднялись
после перезагрузки). Сам бот при старте до 5 минут пытается дождаться доступности БД
(`DB_CONNECT_MAX_ATTEMPTS` в `bot/main.py`), а после подключения сразу шлёт сообщение с курсами
и, если был простой, — сколько он длился (`STARTUP_REPORT` в `.env` управляет тем, кому слать:
всем, только владельцу или никому).

Альтернатива — Docker: `docker compose up -d --build` (см. комментарии в `docker-compose.yml`
про подключение к PostgreSQL на хосте).

## Команды бота

Все действия продублированы кнопками — команды нужны, только если удобнее текстом.

| Команда | Что делает |
|---|---|
| `/start` | Запуск, приветствие, обработка приглашений |
| `/rates` | Курсы сейчас |
| `/alerts` | Список ваших алертов |
| `/alert 90000` | Быстрое создание алерта |
| `/reports` | Включить/выключить время сводок |
| `/menu`, `/help`, `/id` | Меню, справка, ваш Telegram ID |
| `/invite` `/users` `/adduser <id>` `/removeuser <id>` `/status` | Только для владельца |

## Тесты

```bash
pip install -r requirements-dev.txt
docker run -d --name btc-tracker-test-pg -e POSTGRES_PASSWORD=test_pw \
  -e POSTGRES_USER=btc_bot -e POSTGRES_DB=btc_tracker -p 55432:5432 postgres:16-alpine
pytest
```

Тесты чистой логики (парсинг цены, агрегация курсов, гистерезис алертов, расписание сводок)
не требуют БД. Тесты `test_db.py`, `test_access_service.py`, `test_alert_service.py`,
`test_scheduler_reports.py` используют реальный PostgreSQL и аккуратно пропускаются
(`pytest.skip`), если `TEST_DATABASE_URL` недоступен.

## Что стоит донастроить под себя

- **Источники курсов** — в `bot/rates/btc_providers.py` и `bot/rates/fiat_providers.py`: список
  бирж/API, легко добавить свой источник (одна функция разбора + запись в `DEFAULT_*_PROVIDERS`).
- **Тексты** — всё в `bot/texts.py`, одним файлом.
- **Расписание, лимиты, тайминги** — все через `.env`, см. `.env.example`.
